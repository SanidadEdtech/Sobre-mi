# Vera López · CV web

Código de mi CV web, publicado en [sobremi.sanidadedtech.es](https://sobremi.sanidadedtech.es).

> **EN** · Source of my trilingual web CV (Spanish, English and French).

## Tecnología

- Página única en HTML, CSS y JavaScript, sin frameworks.
- Sistema propio de traducción a tres idiomas (ES/EN/FR) con detección del idioma del navegador.
- Diseño adaptable, accesible y preparado para imprimir.
- Datos estructurados de Schema.org y etiquetas `hreflang`.
- Publicado con GitHub Pages en un subdominio propio.
